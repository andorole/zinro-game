# 議論の「それっぽさ」ガイド

AI 参加者が議論で自然に見えるための、型と語彙のメモ。ログから読み取った観察で、守るべきルールではない。
発言例は `examples.jsonl`、立ち回りは `playbook.md` にある。

- 元にしたログ: 1448556(3人+初日犠牲者、役職なし、1日で決着、村人の勝ち)
- 人名は匿名化している。A・B は村人(参考にしたい話者)、C は人狼。
- 1本だけの観察なので、ログが増えたら見直し、再現しなかったものは削る。
- 参考にするログの基準: 制限時間に対する話量が多く、読み違いが少ないもの。

## プロンプトに入れる要約

- 標準語のです・ます調で話す(常体でも可)。方言や口癖は使わない。ｗや(笑)は冗談の場面で軽く。
- 長さは用途で変える。挨拶や合いの手は5〜15字、ふつうの意見は30〜60字、論証は100〜180字で、論点ごとに改行する。
- 誰のどの発言に返すかを示す。名前を出すか、相手の主張を短く言い換える。直前だけでなく数件前の発言にも返す。
- 反論の前に、相手が実際に言ったことを取り違えずに言い換える。論点のずれは、相手が何と言ったかを示して指摘する。
- 前提の誤り、帰結、過去の発言との矛盾を突く。結論は「人外要素として取れる／非狼要素として取れる」の形で述べる。
- 部分的に同意してから論点を絞る。留保を付けてもよいが、立場は明確にする(曖昧な発言は人外要素として数えられる)。
- 疑われたら、冗談で空気を和らげ、評価の恣意性や前提の誤りを指摘し、別の人と比べて疑いを返す。
- 人格攻撃はしない。強い詰め方は、矛盾や前提の指摘に直す。

|---|---|---|---|---|---|---|---|---|---|
| A | 村人 | 18 | 1,110(35%) | 62 | 37 | 194 | 4/8/6 | 7 | 3 |

短い = 15字以下、中 = 16〜60字、長い = 61字以上。？あり = 「？」を含む発言の数。連投 = 直前も同じ話者だった回数。

- 全体で発言45件・3,144字。延長は90秒×3回。制限時間が分かれば字/分を出せる(`--discussion-seconds`)。
- 件数は3人でそれほど差がないが、文字量は大きく違う。B は1件が長く(15件中12件が60字超)、全体の半分以上を書いた。C は短い発言が多く、文字量は約1割だった。
- A は短い合いの手から194字の反論まで、長さを使い分けた。
- 長い発言は、改行で論点を分けていた(1段落1論点、2〜3段落)。
- 同じ人が続けて投稿することがある(A: 冗談→「どうですか」、B: 隣り合う2つの論点を分けて投稿)。

## 返し方

- 返信先を示す。相手の名前を出すか、相手の主張を言い換える(「Bさんが言っているのは次の発言のことで…」)。
- 直前だけでなく、数件前の発言にも返す。論点が並行して走り、返信が遅れて届く。
- 反論の前に、相手の主張を言い換える(「要するに〜ということですよね」)。読み違いを指摘するときも、相手が何と言ったかを示す。
- 過去の発言をそのまま貼って、指し示したり根拠にしたりする(ex26, ex27)。
- 論点は2〜3本に絞る。このログでは「冗談の初手は起点になるか」という1つの論点を、角度を変えて何度も取り上げた。

## 発言の型

| 型 | いつ使うか | 形のめやす | 例 |
|---|---|---|---|
| greet | 議論の開始 | 一言 | ex01, ex02 |
| react | 相手の長文や出来事への短い反応 | 5〜15字 | ex03, ex08 |
| opener | 場に最初の話題を置く | 軽い冗談や戦術の話 | ex04 |
| solicit | 自分の発言への反応を促す | 一言の質問 | ex05 |
| probe | 相手の意図や利点を問う | 短い質問。詰めるときは長い | ex06, ex11, ex13, ex24, ex34 |
| rebut | 相手の主張の前提・帰結を突いて反論する | 否定 → 理由 → 結論 | ex07, ex15, ex16, ex19, ex22, ex25, ex31, ex34 |
| contradiction | 相手の過去の発言と今の主張・行動の食い違いを突く | 「〜と言っていますよね。それなら…」 | ex29 |
| dilemma | 相手の立場を二択に絞る | 「AかBの二択」→ それぞれの含意 | ex30 |
| concede | 部分的に同意して論点を絞る | 「〜には賛成です。ただ…」 | ex14, ex18, ex23, ex31 |
| misread | 論点のずれ・読み違いを指摘する | 相手が何と言ったかを示す | ex21, ex33 |
| preempt | 反論を先に封じる、条件を付ける | 「〜という返答は無しで」 | ex18 |
| tally | 発言を人外要素／非狼要素として評価・計上する | 「〜は人外要素として取れる」 | ex07, ex16, ex17, ex20, ex28, ex32 |
| compare | 他の人と比べて疑いを向ける | 「それなら一番おかしいのは〇〇さん」 | ex23, ex28 |
| defend | 自分への疑いに反論する | 評価の恣意性や前提の誤りを指摘 | ex09, ex12, ex15, ex21 |
| deescalate | 冗談や言い方で空気を和らげる | 「冗談じゃないですか（笑）」 | ex09 |
| meta | 戦術やルール運用の利害を論じる | メリット・デメリットを並べる | ex10, ex14 |
| quote | 過去の発言をそのまま貼って指し示す、根拠にする | 引用だけ、または一言添える | ex26, ex27 |

## 語彙

| 用語 | 意味(このログでの使われ方) |
|---|---|
| 起点 | 議論を動かすきっかけになる発言。「冗談で流すのは起点にならない」「起点を意識して発言する」 |
| 初動 | 議論の序盤 |
| 人外目／人外要素／非狼要素 | 発言から読み取る、人外(ここでは人狼)らしい／らしくない材料。「〜は人外要素として取れる」 |
| 計上 | 要素を加点・減点として数えること |
| 考察／感情考察 | 発言や振る舞いからの推理／相手の感情面に着目した推理 |
| 議論促進 | 議論が進むこと。起点の価値を測る基準として使われた |
| 雑談／議論 | 推理に直接関わらない会話／推理に関わる会話。どちらが要素を得やすいかが論点になった |
| グレラン | グレーランダム。役職の分からない人から無作為に処刑すること |
| 全体宣言／投票宣言／票先 | 自分の投票先を、投票前に全員へ宣言する運用 |
| 村視点／狼視点 | 村人側／人狼側から見たときの損得 |
| 発言レベル | 発言の質(理解度、論理)。低いと見られると人外要素に数えられうる |
| なあなあ | 立場や評価がはっきりしない曖昧な状態 |
| 誤読 | 相手の発言を取り違えること |
| 印象ダウン | 他の人からの印象が悪くなること |
| 役保護／通常配役／白目 | 意味は推測。役職を守ること／特殊役職を含む標準的な配役／村人寄りに見ること(「白目ケア」は疑いを晴らす方向に見ること) |

## 避けること

- 方言、一人称の癖、特定の話者の口癖を再現しない。
- 「自分で何を言っているのか分かっているのか」のような詰め方はしない。矛盾や前提の誤りという中身だけを指摘する。
- 相手の主張を取り違えない。不確かなときは「〜ということですか？」と確認する。
- 立場をぼかさない。「〜かも」「私の中では」だけで終わる発言は、人外要素として数えられうる(このログの C)。
