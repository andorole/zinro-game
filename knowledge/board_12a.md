# 盤面整理(12A猫)のメモ

12A猫は、チャットの練習部屋より先に、盤面の学習から始める(依頼者の方針)。実際の初心者も、盤面整理から始める。
可能性を入れながら、今の環境(定番)を確かめ、詰み進行などを学ぶ。
このメモは、そのための知識の置き場。事実(ログ・依頼者の話)と、解釈・推測を分けて書く。推測は「(推測)」と書き、依頼者に確かめたいことは、末尾の「確認したいこと」にまとめた。
元にしたのは、log17(12A猫。`normal_12a.md`)の1本と、依頼者に聞いた環境の話。盤面の計算は、`python -m zinro_learn board`(`zinro_learn/board.py`)で再現できる。
依頼者が持ち込んだ 11A の確率論のまとめは `prob_11a.md` に置いた。12A猫ではなく、前提が今の環境とずれているので、使い方は「11A のメモとの関係」に書いた。

## 依頼者に聞いた環境(今の12A猫)

- 占い2・霊能1の名乗り(2-1)なら、占いは本物と人狼、霊能は本物(真狼-真)が定番。
- どの盤面でも、だいたい霊能は本物。
- 学ぶこと: 盤面整理、可能性、環境の確認、詰み進行。
- 詰み・詰み進行は、「勝敗が盤面から決まること／確定が連鎖して、残りの手順が決まっていく進行」という読みで合っている(依頼者に確認済み)。
- 2-1 で、占いが初手に対抗白を出したら、今の環境では、出したのは人狼の確率が高い。内訳が真狼だと、本物は対抗(人狼)に白を出せないから。真狂なら対抗白は成立する(本物が狂人に白を出す)ので、そこは環境の問題。
- 初手の対抗黒や、初手のグレーへの黒は、真目になる。人外の凸はそもそも最良手ではないので、真が黒を当てる方が、環境の比率としては大きい。
- 3-1 の対抗黒は、結構真目。狩人は、霊護衛でなく、黒を出した占いの護衛を固定するまである。初手の黒は、とにかく真目が多い環境。
- 偽の占いが、初手に対抗へ白を出す(対抗白)のは、8割偽目。真狂狼-真は、対抗白を出した側が本物でありうる、いちばん有利な盤面だが、そこでもこうなる(組み合わせ論)。3-1 の対抗白も同じ。
- 3-1 は、12A猫でも真狂狼がまだ多い。真狼狼もありうる。
- 盤面だけで言うなら、対抗黒を出した占いはかなり強い。だいたいそっちを真と見て、その占いを護衛する。人狼や狂人が真に黒を当てることもあるが、前者の方が多い。発言ももちろん見て、発言で「さすがに偽」となったら(主観)、霊護衛にする。対抗(黒を出された方)の吊りは、免れない。
- 偽の二手目は、だいたい白。偽の身内切り(仲間に黒)は、戦術としてあまり強くないので、基本は初手や次手で囲う(仲間に白)。2日目昼(最初の昼)の投票宣言で味方を指定することはあるが、基本は良手ではない。
- 2-1 のうち、真狂(偽が狂人)の割合は、いまの置き方(6%くらい。1割弱)でよい。
- 偽の占いが、初手に人狼でない人へ黒を出す割合は、白を出す場合の「1割よりはある。2割程度」。
- 狩人が護衛を固定する目安は、黒を出した側が本物の見込みで 7割台くらい。
- 2割だと 3-1 の対抗黒が 6割台で足りないので、「偽の黒は 1.5割にしよう。3-1 の真狼狼を 2.5 にすれば丁度良さそう」と決めた(3-1 の真狂狼 : 真狼狼は 7.5 : 2.5)。
- 「初手」は、その人の最初の結果(名乗りと同時に出す結果)で合っている。
- 初日の占いは、いまはランオフ(ランダムなし)で、占い師が選ぶ形。
- ギドラ(吊りの指定が自分に当たった役職持ちが、役職を名乗って回避すること)は、指定されたときは、むしろ推奨。指示役の指示がありそうなら基本出るし、指示役から指定が飛ばなければ、出ない方がよい場合もある。対抗がいるなら、猫又は基本的に露出した方がよい。黒を出されたときのギドラCOは、ありえない。
- RCO は、ロケットCO(一発言目に CO すること)。12A猫では、占いと霊能は RCO で名乗る。狐のない配役では、ロケットCOが強いので、決まりというより約束事として、占霊の潜伏は「ない」。
- 12A猫では、占いと霊能は RCO なので、ギドラをするのは狩人と猫又に限られる。
- 猫又は、吊られたらランダム(生存者から1人)、噛まれたら人狼のうちランダムを道連れにする(人狼online仕様。よみ鯖仕様は、噛んだ人狼)。実際に入れるときは、この online 仕様に従う、と聞いた(この計算も online 仕様)。人狼道連れもあるが、村道連れもあるので、真猫は吊りたくない。「対抗がいるなら猫又は露出」の「対抗」は、猫の対抗(猫を騙る人狼や狂人)のこと(確認済み)。
- 狼は、露出した猫又を、たまに噛む。LW のときは絶対に噛めない。人狼2人で夜に6人のときは、猫又を噛めば一気に最終日に行ける。ただし、ランダムな道連れと、猫の対抗(人狼や狂人の偽の猫)が出ることがあるので、最近はあまり噛まない。
- 「真猫に黒刺されたら RPP スタート」(log17 の人狼チャットの言葉。依頼者の説明): 偽の占いが真猫に黒を出す→真猫が猫COする→対抗の猫が出る→黒を出された真猫が吊られる(黒を出された人の吊りは免れない)→道連れが人外に当たらず、村に当たる(村道連れ)→2回目の昼(依頼者の数え方で3日目昼)に、狼3・狂1・村4の8人盤面になる→人外側が RPP を宣言して、4:4で RPP する。人数は、12人 − ダミー(夜0) − 猫 − 村の道連れ − 夜1の噛み = 8人。昼1に11人が生きていて、道連れが猫以外の10人から無作為なら、村に当たるのは 6/10、人狼は 3/10、狂人は 1/10(人外に当たると、この流れにはならない)。RPP は、同数なら抽選のパワープレイで合っている(依頼者に確認済み)。
- 進行の目安(依頼者): 3-1 白白白(黒が出ない)は、占いロラ進行で確定。3-1 で黒が出たら、先黒吊りになる可能性が高い。1-1 は、霊指定から決め打ちになりやすい。昼2で黒が出た場合は、本格的に占い対黒のどちらかになる。白が出た場合の決め打ちは、占いか、占いがまだ占っていない所のどれかを、霊が指定する感じ(1-1 の細部は確認したい)。
- 2-2 は、基本的に霊ロラ進行。ただし、黒が出たら、黒を先に吊ることもある。3-2 は、2騙り以上が確定。3-2 で、霊ロラと占いロラのどちらがよいかは、依頼者もまだ分かっていない(計算で確かめたいこと。霊能の名乗りが2人の盤面は、まだ扱えない)。
- 4-1 は、全騙り(偽の3人が人狼3人)なら詰み盤面: 占いロラ完遂をすれば終わってしまう。真狂狼狼の場合は、占いを吊り切って最終日。ただし、このCO数だと、普通に狼側が不利(依頼者)。霊が3人(2-3 など)は、そもそもあまり起こらない。もしなったら霊ロラ。これも村有利寄り。
- 人狼・狂人のギドラ(依頼者): 黒なしで指定されたときの、狂人のギドラ・人狼のギドラが、かなり悩ましい(黒を出されたときの話ではない)。初手の回避には、偽の狩人COがよいことがある。ただ、COなしで普通に沈んで(吊られて)、村らしさ(村感)を見せられることもある。猫COは炙りに使える(炙り: 偽の猫として扱われると分かっていながら、猫COをして、対抗を出す行動。指定されたときなどの足掻き)。「1猫は真」(猫の名乗りが1人なら本物)と読まれるので、猫の名乗りには、一応、対抗を出したい(この計算の、対抗猫が出る置き方と同じ向き)。対抗伏せ貫通(猫COを偽と割り切って、対抗を出さずに吊ること)は、いまはやっていない(この計算も、対抗が出ない猫は吊らない)。狩COにこれをするのは勇気がいるので、初手(昼1)では、狩貫通はしない。そのため、初手の回避には、偽の狩人COが通りやすい(推測)。人外の偽の狩人CO(黒なしで指定されたときの初手の回避)と、指定されたときの炙りは、この計算に入れていない(偽の猫が先に自分から出る `FAKE_CAT_PROACTIVE` は、炙りに近いが、指定とは結びつけていない)。
- 吊られそうな場合や、ギリ指定(討論の終わりぎわの指定)にも対応できるようにしておく(依頼者)。「吊られるのに CO しなかった」は、あまりにも致命的。
- ギドラの出し入れ(依頼者): 本指定のタイミングで、指定された猫又も狩人もギドラCOをする(この計算は、猫又だけ)。ギドラ解除は、たいてい霊(指示役)の指示で行う。村の議論で解除することもあるが、AI が参加する場合は、霊の指示に従う(霊指示準拠)方がよい。この計算の「指定された猫が名乗り、対抗猫が出なければ、村は吊り先を選び直す」は、霊指示準拠の解除にあたる。
- 2-1白進行(依頼者): たぶんいちばん多い進行。占い2者がグレーを仮指定し、霊能者が本指定を行う。本指定のタイミングで、指定された猫はギドラCOをする(この計算の、指定されたら名乗る猫と同じ形)。
- 猫の名乗りと吊り(依頼者): いまの環境では、猫COして対抗の猫が出たら、猫吊りが基本。占いへの対抗黒と同じ型で、可能性をすべて考えるより、環境上確率が高い盤面を想定した吊り・狩人の護衛になっている。
  - 猫が2人名乗ったとき、吊るのは、黒を出された方。黒がなければ、どちらかといえば先に出た方。先に出たのが偽の割合は、仮に置いた 6割でよい。優先は、黒先、次に猫吊り、そのあとに進行。
  - 吊った猫の道連れが起きたら、本物を吊ったことになり、ほぼ負け(村道連れで人数が減り、RPP になる)。道連れが起きなければ、偽を吊れたことが確定する。2人の猫から1人を吊って道連れが起きなかったら、残る猫(真猫)は放置する。
  - 猫COのあとに対抗猫が出る割合は、仮に置いた「7割。出すのは人狼 : 狂人 = 7 : 3」でよい(対抗猫はまあまあ出る)。
  - 猫が出るのは、昼1だと、黒を出された場合と、吊りを指定された場合。黒を刺された場合は100%、必ず出る。進行提示が黒吊りの場合は、黒を刺された猫は絶対に出る(伏せたまま吊られることは絶対にない)。ただし、人狼側は猫を確定させたくないので、対抗が出て、真猫が貫通される(CO しても吊られる)のが基本。3-1 で占いロラ進行になった場合だけ、猫が伏せる可能性がある(猫は噛まれないので、依頼者は出てもよいと思う)。今の環境では、先黒吊りになる可能性が高く、そのときは絶対に CO しないといけない。
  - 猫のRCO(昼1に即CO)は、今の環境だと、しないことが多い。昼1に即猫COは、基本的にない。2-2 盤面は、グレー噛みが起きやすく、RCOのメリットが少ない。3日目(2回目の昼)に猫COするのはあり。2-2 盤面を見ずに、朝一で即露出するのは、あまり好ましくない(先に聞いた「2-2は即出てもいいかも」は、こちらに直った)。
  - 指定された猫は、指示役から「単体で出してほしい」と言われたら、単体で出る(ほかのギドラ=狩人は出ない。「1ギドラ出たら全ギドラ出し」にはならない)。
  - 狩人の護衛は、初手で黒が出された場合は、黒を出した占い(依頼者に確認済み。「黒を出された」は言い間違い)。黒がなければ、真目の占いか霊能。
  - 護衛は、猫又の噛みを防げる(防げれば、道連れも起きない)。
  - RPP は、同数なら抽選のパワープレイで合っている(4:4で、狼と狂人が同じ人に票を入れ、同数になると抽選)。
- 3-1 の進行は、いまは占いロラが主流。3-1 のギドラグレランは、いまはしない。
- これは依頼者の話で、ログから数えたものではない(12A猫のログは1本だけ)。log17 は、これと合う(2-1で、真狼-真。初手のグレーへの黒を出した L が本物)。

## 用語(推測を含む)

| 用語 | 意味 |
|---|---|
| 盤面 | ある時点で公開されている情報(名乗り、結果、処刑、死亡、狼CO)と、そこから読める可能性の全体(推測) |
| 占い-霊(2-1 など) | 占い師を名乗った人数 - 霊能者を名乗った人数。0-1 は、占いの名乗りがなく、霊能の名乗りが1人 |
| 真・狼・狂 | 名乗った人が、本物・人狼の騙り・狂人の騙り。「真狼-真」は、占いが本物と人狼、霊能が本物(依頼者の言い方) |
| 灰 | 名乗っておらず、白も黒も出ていない人 |
| 確白・確黒 | 白・黒が確定した人。ここでは、「定番の世界のすべてで白(黒)」の人を、その目安にした(推測) |
| 対抗白・対抗黒 | 占いが、もう一方の占い(対抗)に出した白・黒。「初手の対抗白」は、その人の最初の結果が、対抗への白(初手の読みは、確認したい) |
| 初手 | その人の最初の結果。名乗りと同時に出す結果(log17 の昼1)。依頼者に確認済み |
| ランオフ | 初日の占いのランダムがオフ。占い師が初日の相手を選ぶ(いまの12A猫の設定。依頼者の言い方で、意味は私の読み)。log17 の L が初日に黒(M)を引けたのも、選べる形だったから、と読める |
| 凸 | 人外(偽の占い)が、人狼でない人に黒を出して、勝負をかけること。最良手ではない、と依頼者は言う |
| 相互白 | 占い2人が、互いに白を出し合うこと。本物は狼に白を出せないので、組には必ず狂人がいる(11A のメモ) |
| 猫又・道連れ | 吊られたら生存者から1人(ランダム)、噛まれたら人狼のうちランダム(人狼online仕様。実際に入れるときもこちら。よみ鯖仕様は、噛んだ人狼)を道連れにする。人狼を連れていくのが人狼(人外)道連れ、村を連れていくのが村道連れ。真猫は吊りたくない。狼は、露出した猫を、たまに噛む(LW は絶対に噛めない。2w・夜に6人なら、噛めば一気に最終日に行ける)が、最近はあまり噛まない。猫の「対抗」は、猫を騙る人狼や狂人 |
| RPP・PP | PP は、パワープレイ(人外側が票をそろえて、村人を吊ること)。RPP は、同数なら抽選のパワープレイ(依頼者に確認済み。R はランダムと読んだ)。人外側が村より多ければ、必ず通る(PP)。依頼者の説明では、偽の占いが真猫に黒を出す→真猫が猫CO→対抗の猫が出る→黒を出された真猫が吊られる→道連れが村に当たる→2回目の昼に狼3・狂1・村4の8人盤面になり、人外側が RPP を宣言して、4:4で RPP する |
| 猫吊り・対抗猫 | 対抗猫は、猫の名乗りに対抗して出る猫(猫を騙る人狼や狂人)。猫吊りは、猫の名乗り2人から1人を吊ること。いまは「猫COして対抗猫が出たら猫吊り」が基本で、占いへの対抗黒と同じ型。可能性をすべて考えるより、環境上確率が高い盤面を想定した吊り・狩人の護衛になっている。吊るのは、黒を出された方、なければ先に出た方。道連れが起きたら本物を吊ったことになり(ほぼ負け)、起きなければ偽が確定して、残る猫は放置(依頼者) |
| ギドラ(CO) | 吊りの指定が自分に当たった役職持ちが、役職を名乗って吊りを避けること。12A猫では、占いと霊能は RCO で出ているので、狩人と猫又に限られる。1人が出たら、ほかの役職持ちも出す運用(「1ギドラ出たら全ギドラ出し」)がある(依頼者の説明と log17)。黒を出された人のギドラCOはない |
| 炙り・対抗伏せ貫通・狩貫通 | 炙りは、偽の猫として扱われると分かっていながら、猫COをして、対抗を出す行動。指定されたときなどの足掻き(依頼者)。対抗伏せ貫通は、猫COを偽と割り切って、対抗を出さずに吊ること。いまはやっていない(依頼者)。狩COにこれをする(狩貫通。呼び方は推測)のは、勇気がいる。初手(昼1)では、狩貫通はしない(依頼者) |
| 指示役 | 吊り先の指定(指示)を出す役。ギドラCOをするかは、指示役の指示がありそうかで決まる。log17 では霊能の J が「指定：D」「指定F」を出し、ほぼ全員が従った(どの役がなるかは確認したい) |
| RCO(ロケットCO) | 一発言目に CO すること(依頼者の説明)。12A猫では、占いと霊能は RCO で名乗る。狐のない配役では強いので、約束事として、占霊の潜伏は「ない」。log17 の L は「【占いRCO】Mさん→黒」と名乗った。log17 の人狼チャットの「占RCO必須ルールが消えた」「RCO必須じゃない…?」は、その部屋の設定の話と読める(推測) |
| 占いロラ・グレラン | 占いロラは、占いの名乗りを順に吊る進め方。グレランは、灰(役職の分からない人)から無作為に吊る進め方。3-1 は、いまは占いロラが主流(依頼者)。log11 の試合後の雑談に、3-1 の進行として「3-1ギドラグレラン、猫出しグレラン、グレラン、占いロラ」が並んでいた |
| 切り・囲い | 切り(身内切り)は、偽の占い(人狼)が、仲間に黒を出して、本物らしく見せること(log17 の D が昼2にした。解釈)。戦術としてあまり強くない(依頼者)。囲いは、仲間に白を出して守ること。基本は、初手や次手で囲う(依頼者)。2日目昼の投票宣言で味方を指定することもあるが、基本は良手ではない |
| 縄・縄数 | 吊れる回数。ここでは、人間を吊って外してしまっても負けない回数を「外せる回数」、それ + 1 を縄数とした(推測) |
| 灰詰め | 灰を端から吊って、人狼を吊りきること |
| 詰み・詰み進行 | 勝敗が盤面から決まること／確定が連鎖して、残りの手順が決まっていく進め方(依頼者に、この読みで合っていると確認した) |

## 盤面整理の手順

初心者が最初に覚える型を、機械でたどれるようにした。

1. 名乗りを数える。占い-霊(2-1 など)と、名乗った人・出した結果(だれに白・黒)を書く。
2. 名乗った人ごとに、真・狼・狂を並べる。本物は、占い・霊能とも1人だけ。名乗りに本物がいなければ、本物は潜伏している。
3. 環境で、定番・ありうる・まれに分ける(規則は下)。
4. 公開された事実で、絞る。
   - 本物の占い師・霊能者の結果は正しい(黒は人狼、白は人狼でない。狂人は白)。偽の結果は、何でもよい。
   - 夜に襲撃で死んだ人は、人狼でない。狼COした人は、人狼。
   - 勝負が続いているので、人狼は生きていて、人間より少ない。
5. 結果の出し方で、見込みを動かす(下の「結果の出し方の癖」)。初手の黒(対抗黒・グレーへの黒)は真目、2-1 の初手の対抗白は人狼目、3-1 の対抗白は偽目。
6. 確定したことを出す。定番の世界のすべてで黒(白)の人。ありうる・まれまで広げても変わらないことは、確実。
7. 縄を数える。生存者と人狼の数から、外せる回数と、灰詰めで足りるか。
8. 次を決める。定番で確定した黒を吊る。ただし、定番から外れる動き(切りなど)を、「まれ」として頭に置く。

## 定番・ありうる・まれの規則(仮)

依頼者に聞いた環境を、規則にしたもの。実戦の比率ではなく、目安(`board.py` の `world_judgement`)。

| 段階 | 条件 |
|---|---|
| 定番 | 占い・霊能とも、名乗りに本物がいる。偽が1人なら、偽は人狼(2-1 の真狼)。偽が2人以上なら、狂人が1人まじる(3-1 の真狂狼) |
| ありうる | 偽が1人で、それが狂人(2-1 の真狂)。偽が2人以上で、狂人がまじらない(3-1 の真狼狼) |
| まれ | 偽の黒が、人狼に当たる(仲間への黒=切り、狂人の偶然) |
| ない | 名乗りに本物がいない(本物が潜伏。霊の偽が、本物の霊を隠すのも同じ)。占い・霊能の本物は、ロケットCOで名乗るので、世界から外した(`Board.rco`) |

- 2-1 で真狼-真が定番になるのは、この規則から出る。霊が偽(霊の名乗りに本物がいない)は、「霊はだいたい真」なので、まれ。
- 3-1 の真狂狼が多いのは、依頼者の話。偽が3人(4-1)以上でも、狂人がまじる形を定番と読んだ(推測。確認したい)。
- 世界ごとに、定番でない理由が残る(複数あるときは、いちばん低い段階)。
- 段階には、重みの仮の数字をつけた(1通りあたり、定番 1・ありうる 0.2・まれ 0.005)。まれは、いまは切り・偶然だけ。実戦の比率ではない。
- 霊の名乗りが1人なら、その人は本物(ロケットCOで、本物は必ず名乗るため)。霊の偽が出るのは、霊の名乗りが2人のとき。
- ありうるのうち、偽が2人以上で人狼だけの世界(3-1 の真狼狼)は、1通りの重みを 1/3 にした。3-1 の真狂狼 : 真狼狼 が 7.5 : 2.5 になる大きさ(依頼者の数字)。2-1 の真狂(0.2。2-1 のうち6%くらい)は、「いまの置き方でよい」ので動かしていない。

## 結果の出し方の癖(環境での扱い)

占いの初手の結果は、本物と偽(人狼・狂人)で、出し方が違う。依頼者に聞いた読みを、次のように盤面の計算に入れた(`board.py` の `result_factor`)。

| 初手の結果 | 依頼者の話 | 計算での入れ方 |
|---|---|---|
| 2-1 の対抗白 | 出したのは人狼の確率が高い。真狼だと、本物は対抗(人狼)に白を出せない。真狂なら成立するが、それは環境の問題 | 本物が人狼に白を出す世界は、真偽の条件で成り立たない。真狂の割合は、「狂人が偽に出る=ありうる」の重みで決まる |
| 初手の対抗黒・グレーへの黒 | 真目。人外の凸は最良手ではなく、真が黒を当てる方が、環境の比率としては大きい。3-1 の対抗黒は結構真目で、狩人が黒を出した占いの護衛を固定するまである(目安は本物の見込み 7割台)。初手黒は、とにかく真目が多い | 偽の占いが、初手に人狼でない人へ黒を出す重みを、`FAKE_BLACK_FIRST`(依頼者の判断で 0.15)にする(白を出す場合を 1 としたときの比)。人狼への黒(切り・偶然)は、段階(まれ)で扱う。3-1 の対抗黒で、黒を出した側が本物の見込みは 75%(護衛固定の目安 7割台に合う)。狩人の護衛は、盤面の計算に入れていない |
| 初手の対抗白(3-1 も) | 8割偽目。いちばん有利な真狂狼-真でも、そうなる | 偽の白は、割り引かない。真狂狼-真では、本物が対抗白を出せる相手は狂人だけなので、出した側が本物の見込みは 2割(11A のメモと同じ数え方)。真狼狼では、出した側は必ず偽 |

重みは仮。この重みで、占い A が初手に結果を出したときの、A の種類の見込みは次のとおり。3-1 は、真狂狼が多く、真狼狼もある、の重み。段階ごとの出力(`python -m zinro_learn board`)と同じ数え方。

| 盤面 | A が真 | A が狼 | A が狂 |
|---|---|---|---|
| 2-1・初手の対抗白(A が B に白) | 6% | 88% | 6% |
| 2-1・初手の対抗黒(A が B に黒) | 86% | 13% | 1% |
| 2-1・初手のグレーへの黒(A が D に黒) | 70% | 29% | 2% |
| 2-1・初手のグレーへの白(A が D に白) | 43% | 54% | 4% |
| 3-1・初手の対抗白(A が B に白) | 16% | 53% | 32% |
| 3-1・初手の対抗黒(A が B に黒) | 75% | 18% | 7% |
| 3-1・初手のグレーへの黒(A が D に黒) | 52% | 31% | 17% |
| (比べる)2-1・二手目以降のグレーへの黒(癖を入れない) | 26% | 70% | 4% |

- 見るのは、順序と向き。対抗白は人狼目、対抗黒とグレーへの黒は真目、グレーへの白はやや偽寄りの五分、3-1 の対抗白は8割偽目。数字そのものは、仮の重みの結果。
- 偽が初手に黒を出す重みを上げると、黒の真目は薄れる(0.5 にすると、2-1 のグレーへの黒は真が 4割を切る)。置き方の経緯: 最初は 0.2 → 話が強まって 0.1 → 「1割よりはある。2割程度」で 0.2 → 3-1 の対抗黒が 6割台で足りず、「1.5割にしよう。真狼狼を2.5にすれば丁度良さそう」で、いまの 0.15 と 真狂狼 7.5 : 真狼狼 2.5。

対抗白を出した側が本物の見込みは、「2-1 の盤面のうち、偽が狂人(真狂)の割合」で決まる。真狂の重みを変えると、次のように動く。

| 真狂の重み(1通りあたり) | 2-1 のうち真狂の割合 | 対抗白を出した A が真 | A が狼 |
|---|---|---|---|
| 0.1 | 3% | 3% | 94% |
| 0.2(いまの仮) | 6% | 6% | 88% |
| 0.4 | 12% | 11% | 79% |
| 0.75 | 20% | 17% | 67% |
| 1.5 | 33% | 25% | 50% |

- 11A のメモ(第2部)の式は、本物が出した見込み = q / (q + 1 + z)(q は 2-1 の偽が狂人である割合、z は占いが両方偽の割合)。上の表は、同じ関係を数えたもの(偽の白は割り引かない)。
- 「今の環境」の q がどのくらいかは、依頼者に聞かないと決まらない。確認したいことの 1 に入れた。

## 11A のメモとの関係

`prob_11a.md` は、依頼者が持ち込んだ 11A(人狼2・占い師1・霊能者1・狩人1・狂人1・村人5。初日犠牲者の役職が欠ける)の確率論のまとめ。12A猫ではない(人狼が2人、猫又がない)。第2部の数字は、「狂人の占い騙り90%」など、狂人の露出が高い前提で、今の環境とずれている(依頼者の注意)。

- 使う(第1部。ルールから出る結論)
  - 真占いは、狼に白を出せない(黒になる)。
  - 対抗白の矢は、本物が出すなら1本(本物→狂人だけ)、偽が出すなら (n-1)^2 本。出した側が本物の見込みは 1/(1+(n-1)^2)。2-1 は 50%、3-1 は 20%、4-1 は 10%。2-1 の 50% は、本物側の天井。
  - 相互白のペアには、必ず狂人がいる。
  - 確定した狂人を吊るのは、縄の純損(狂人は村人側の人数に数えるので、吊っても縄の総数は変わらない。外れるとわかっている的に、縄を1本使うこと)。
  - 偽の結果は何でもよいが、本物がグレーを占って黒を引くのは少ない(11A では 1/9)。グレーへの黒は、偽の黒の頻度が低いほど真目。
- 使わない(第2部。行動の前提を置いた数字): 盤面の割合(2-1 が 32% など)、「2-1 の対抗白」の表、2-2・3-2 の最適手など。騙り率の前提が違えば、反転しうる。
- 再現: 11A のメモの、3-1(真狂狼-真)で A が対抗 B に白を出したときの種類の見込み(A: 真20%・狂40%・狼40%、B: 真40%・狂40%・狼20%、C: 真40%・狂20%・狼40%)と、上の 50・20・10% は、`board.py` で、癖を入れずに(`fake_black_first=0`)数えると一致する(`tests/test_board.py` の `ElevenAMemoTest`)。メモ 1-3 の、白の出し方ごとの表(相互白、一方向の鎖、グレー白と霊への白の2通り)も、小数第2位まで一致した。「霊に白は真目」は、グレー白が少し偽寄り(本物はグレーで人狼を引くと黒になる)だから、という理由まで、数え方から出る。

## 縄と灰詰めの数え方

- 夜は毎回、襲撃で1人減る(狩人の護衛の成功は数えない)。人狼が、残りの人間と同数以上になったら、人狼の勝ち。
- 外せる回数: 人間を吊ってしまっても、負けない回数。縄数 = 外せる回数 + 1(最後の1回も外すと負け)。

| 昼の初めの盤面 | 外せる回数 | 縄数 |
|---|---|---|
| 生存 11・人狼 3 | 2 回 | 3 |
| 生存 9・人狼 2 | 2 回 | 3 |
| 生存 7・人狼 1 | 2 回 | 3 |
| 生存 5・人狼 1 | 1 回 | 2 |
| 生存 3・人狼 1 | 0 回 | 1 |

- 人狼を1人吊ると、外せる回数が戻る(生存9・人狼2 を、人狼を吊って生存7・人狼1 にしても、外せる回数は2回のまま)。
- 灰詰め: 確定した黒を先に吊り、そのあと灰を端から吊っていく。人狼が灰のいちばん最後に固まっている最悪の並びでも、人狼の勝ちにならないなら、勝ち確(`narrowing_wins`)。灰が多いと足りず、読みが要る。

## 進行の比較(占いロラとグレラン)

依頼者の話: 3-1 の進行は、いまは占いロラが主流。「3-1ギドラグレラン」は、いまはしない。これを、盤面の計算で確かめた(`python -m zinro_learn progress`、`zinro_learn/progress.py`)。

### 1. 昼1の1本目の命中率(厳密。世界の重みだけで出る)

| 盤面 | 占いの名乗り(人狼の見込み) | 灰の1人 |
|---|---|---|
| 2-1・結果なし | 各 47% | 26%(8人) |
| 3-1・結果なし | 各 42% | 25%(7人) |
| 4-1・結果なし | 各 52% | 15%(6人) |
| 3-1・対抗黒(A が B に黒) | A 18%、B 75%、C 41% | 24%(7人) |
| 3-1・グレーへの黒(A が D に黒) | A 31%、B 45%、C 45% | 26%(7人) |

- 3-1 では、占いの名乗り1人が人狼の見込み 42%、灰の1人は 25%。人狼3人のうち、偽の占い(真狂狼なら1人、真狼狼なら2人)が名乗りに入っていて、灰の人狼は少ないから。
- 結果で黒が出ると、黒を出された人は7割台の見込み。黒先を吊るのが一択になる。

### 2. 村の勝率の試算

盤面の世界の重みから役職を引き、進行と狼の噛み方を決めて、勝敗まで動かした(20000 回ずつ。誤差は ±0.3% くらい)。

- 村の進行: グレー(灰を無作為に吊る)、占いロラ(狼の見込みが高い順に吊り、いちばん低い人を残す)、黒スト(占いを吊り、霊能の結果が黒なら灰に切り替える)、ロラ完遂(占いを全員吊る)。どれも、黒を出された人(黒先)を先に吊る(先黒吊り。標準)。占い吊り優先(`black_first` を偽): 占いを吊る進行は、占いの名乗りを先に吊り、黒先は占いを吊り終えてから吊る(依頼者の言う進行提示の、黒吊りと占いロラの違い。グレーは占いがいないので変わらない)。占い吊り優先のとき、黒を刺された猫は、`CAT_HIDE_SEERS_FIRST`(仮に 0.5)の割合で伏せる。
- 狼の噛み方: 灰を噛む(11A のメモの基本の前提)と、名乗りを噛む(狼でない占い・霊能の名乗りを先に噛む。実戦的)。狂人は人間として数える。
- 狩人の護衛(毎晩1人。狼がその人を噛もうとしたら、噛みは失敗する): 表の標準は『環境の護衛』(依頼者の話): 初手で黒が出ていれば、黒を出した占い。なければ、霊能(真目の占いか霊能)。守る相手が死んでいたら、次の候補(黒を出した占い、霊能、真目の占い)。『護衛なし』『霊護衛固定』『黒出し占い護衛固定』は、護衛の表で比べる。11A のメモの比較は、護衛なし。
- 猫又: 吊られたら、生存者からランダムに1人を道連れにする。噛まれたら、人狼のうちランダムに1人を道連れにする(人狼online仕様。実際に入れるときもこの仕様に従う、と聞いた。よみ鯖仕様の「噛んだ人狼」も、噛む人がランダムなら同じ)。上の表は、猫又が隠れていて、黒を刺されたら・指定されたら名乗る前提(`gidra`)。名乗っている猫又は、村が吊らず、狼も噛まない(ほかに候補があるあいだ)。ただし、人狼2人で夜に6人のときは、狼が `OPEN_CAT_BITE`(仮に 2割。「最近はあまり噛まない」)の割合で噛む。LW は絶対に噛まない。
- 猫が名乗り、対抗猫が出る(`counter`): 猫又が昼1から名乗っていて、`COUNTER_CAT`(70%)の割合で、対抗の猫が出る。出すのは、占いを名乗っていない人狼(70%)か狂人。猫が2人名乗っていると、村は猫吊りをする(依頼者): 黒を出された方(黒先)、なければ先に出た方(先に出たのが偽の割合は、仮に `FAKE_CAT_FIRST` 0.6)。吊った猫が本物なら道連れが起きる。起きなければ偽が確定して、残る猫は吊らない(放置)。本物が先に死んで偽が残れば、その偽を、黒先のあとに吊る。黒先は、猫吊りより先に吊る。`counter` は、猫が昼1から名乗っている前提。
- 猫が隠れていて、黒を刺されたら・指定されたら名乗る(`gidra`。標準): 猫又は隠れている。昼1に出るのは、黒を刺されたとき(必ず出る)と、吊りを指定されたとき(単体で名乗る=ギドラ。狩人は出ない。依頼者)。黒を刺された猫は、必ず名乗る(伏せたまま吊られることはない)。名乗っても黒先として吊られる(貫通される)。人狼側は猫を確定させたくないので、対抗猫がほぼ出る(`COUNTER_CAT_BLACK` 0.9。仮)。指定された猫が名乗り、対抗猫が出なければ(`COUNTER_CAT` 0.7 で、あとから出る)、村は吊り先を選び直す(猫は確定して放置)。出れば猫吊りで、先に出た(=指定された本物の)猫を吊る形になり、道連れが起きる。道連れで偽と分かるので、次に偽を吊る。偽の猫が、真猫より先に自分から出ることもある(`FAKE_CAT_PROACTIVE` 0.15。仮)。そのときは、真猫が対抗として露出し、先に出た偽を吊る。この割合は、依頼者の「先に出たのが偽は6割くらい」に近づくように置いた(占いロラで 65%)。占いロラ進行になったときだけ、猫が伏せる可能性がある(標準の先黒吊りでは入れていない。占い吊り優先では、黒を刺された猫が `CAT_HIDE_SEERS_FIRST`(仮に 0.5)の割合で伏せる)。2-2 では、昼1に即出ることは基本ない(3日目に出るのはあり。まだ入れていない)。
- 同数のときの票(RPP): 人外側(人狼と狂人)が、村と同数以上になると、人外側が同じ村人に票を入れる。上回れば通る(PP)。同数なら、村が人外側の1人にまとまっても同数で、抽選(RPP。依頼者に確認済み)。村は、人外側の1人(だれが狂人かは分からない)に、無作為にまとまる、と置いた。狂人が生きているあいだだけ起きる。以下の表は、この操作を入れた前提(`--no-rpp` で外せる)。11A のメモの比較は、この操作がない前提。

- 占い吊り優先で、黒を刺された猫が伏せる割合を 0 → 0.5 → 1 に動かしても、勝率はほとんど動かない(占いロラ・灰を噛む 67% → 66% → 65%)。黒を出された D が猫又なのは 9% で、占い吊り優先の差の主な理由ではない。
- 同数のときの票(RPP)を入れると、灰を噛む前提で、村の勝率が下がる進行がある(3-1・結果なし・夜の結果あり: グレー 54% → 40%、占いロラ 57% → 53%、黒スト 66% → 60%、ロラ完遂 63% → 63%)。名乗りを噛む前提では、ほとんど変わらない(試合が、人外側の残る終盤に入る前に決まるため)。灰を吊る進行(グレー、黒スト)は、狂人を含む人外側が残りやすく、RPP に入りやすい。ロラ完遂は、偽の占い(狂人を含む)を早く吊るので、人外側が減って、影響が小さい。11A のメモの順位(黒スト > ロラ完遂)は、PP がない前提で、RPP を入れると逆になる(3-1・結果なし・灰を噛む・夜の結果あり: 黒スト 66% → 60%、ロラ完遂は 63%)。
- RPP の中身: 村が人外側を絞れていなければ、RPP は無作為の吊りと同じ確率になる(抽選の半分 × 人外側の中の人狼の割合 = 人狼の割合。村が人外側の1人を無作為に選ぶ前提)。人狼3・狂人1・村4(4:4。真猫を吊って道連れが村に当たった形)の村の勝ちは、閉じた式で 1/32(約 3%)。人狼2・狂人1・村3(6人)は 1/12(約 8%)、人狼1・狂人1・村2(4人)は 1/4(約 25%)。エンジンで確かめた 4:4 は、RPP あり 3%・なし 3% で、ほぼ同じ(誤差は 0.5% くらい)。違いが出るのは、村が人狼を絞れているとき: 確定した黒がいる 4:4(占い A が B に黒)は、RPP なし 13% → あり 5%(黒先を吊れても、抽選で半分は村人が吊られる)。
- 真猫に黒を刺された形(偽の占い A が、真猫 E に初手の黒。3-1): 村の勝率は、普通の試合(3-1・結果なしで 28%〜63%)よりはっきり低い(RPP あり・環境の護衛。灰を噛むと 31%〜38%。名乗りを噛むと 30%〜42%で、ロラ完遂が高いのは、黒を出した偽の占いも吊るため)。道連れの行き先で分けると(占いロラ)、村に当たる(村道連れ。60%)と 10%(灰を噛む)・21%(名乗りを噛む)、狂人に当たる(10%)と 80%・40%、人狼に当たる(人狼道連れ。30%)と 78%・58%。村道連れは「ほぼ負け」(依頼者)と合う。2回目の昼の 4:4 は、上のとおり、村の勝ちが約 3% の形。環境の護衛(黒を出した占い=偽の A を守る)は、灰を噛む前提では変わらず、名乗りを噛む前提では上がる(34% 対 18%・占いロラ)が、それでも低い。護衛は噛みを止めるだけなので、黒先として吊られる真猫は守れない。
- 11A のメモの「3-1 全体での進行比較」(黒が出たらグレー転換 50.6% > ロラ完遂 39.2% > グレー詰めのみ 10.3%)と、順位の向きが同じ(同数の票の操作なし・夜の結果なし・灰を噛む前提では、猫又が隠れていても、黒スト 53% > ロラ完遂 47% > グレー 31%)。メモの 2-3 でグレー3連が高いのは、1本目の占い吊りで黒が出たあとの、残る人狼が灰にいる盤面だけの話(と読んだ)。これは、黒ストの「黒が出たら灰に切り替える」に当たる。
- 占いロラが主流になった理由として、計算から言えること: 昼1の1本目の命中率は、占いの名乗りの方が灰より高い(3-1 で 42% 対 25%)。12A猫の3-1 は、人狼3人のうち1〜2人が必ず占いの名乗りにいるので、灰だけでは吊りきれない。占いを先に吊る進行(占いロラ・黒スト・ロラ完遂)が、どの表の、どの行でも、グレーより勝率が上になる。
- 限界: 猫の出方(標準の `gidra`)は、黒を刺されたときと、吊りを指定されたときだけ名乗る。標準の先黒吊りでは、黒を刺された猫は必ず出る(伏せない)。猫が伏せるのは、占い吊り優先(黒先を後回しにする進行)のときだけで、その割合(仮に 0.5)は感度を見ただけ。3日目(2回目の昼)に、盤面を見て猫COすることは、入れていない(昼2に自分から出ることはない、と置いた)。2-2 は、昼1に即出ることは基本ないと聞いたが、霊能2人の盤面が未対応なので、計算していない。偽の猫が自分から先に出る割合(0.15)は仮で、先に出たのが偽の6割に近づくように置いた。指定された猫に対抗猫が出たら、先に出た(指定された)猫を吊る、と置いた。黒を刺された猫への対抗猫の割合(0.9)も仮。狩人のギドラCO(全ギドラ出し)は入れていない。猫吊りの優先は、黒先、次に猫吊り、そのあとに進行(依頼者に確認済み)。護衛は、環境の方針(黒を出した占い、霊能、真目の占いの順)か固定の相手を守るだけで、猫を守らない。発言で「さすがに偽」となって、霊護衛に替えることは入れていない。RPP は、村が人外側の1人(黒と信じる人がいればその人)にまとまる前提で、村が割れることは入れていない。村の読みは、霊能の報告での占いの真偽(`reads`)だけで、発言からの読みは入れていない(報告が出るまで、本物と見る占いは、最初の狼の見込みで決まる)。初手の囲い(偽の初手の白が、仲間に当たりやすいこと)は、盤面の重みに入れていない。偽の癖(黒の重み 0.05、次手の囲い 5割)と、先に出た猫が偽の割合(0.6。`counter` だけで使う)は仮。数字は、仮の重みと仮の噛み方の結果で、実戦の勝率ではない。向きと大小だけを見る。

## 道具

- `python -m zinro_learn board knowledge/boards/<id>.json [--stage N]`: 段階ごとに、合う世界(名乗った人ごとの真・狼・狂)、定番・ありうる・まれ、確定した黒白、縄、灰詰め、答え合わせ(実際の盤面の段階)を出す。
- `python -m zinro_learn board --patterns`: 名乗りの数ごとの、可能性の一覧。
- `python -m zinro_learn progress --seers 3 [--result A:B:黒] [--guard none|medium|blacksayer|env] [--cat off|hidden|open|counter] [--no-rpp]`: 進行の比較(グレー・占いロラ・黒スト・ロラ完遂)の、村の勝率の試算と、昼1の1本目の命中率。`--guard` の既定は env(環境の護衛: 黒を出した占い、なければ霊能)、`--cat counter` は猫が名乗って対抗猫が出る(猫吊り)、`--no-rpp` は人外側の同数の票を入れない(11A のメモと同じ前提は `--guard none --no-rpp`)。
- 盤面の記録(`knowledge/boards/<id>.json`): 公開された情報だけを、段階(stages)ごとに events に書く(co=名乗り、result=占い・霊能の結果、executed=処刑、bitten=襲撃死、dead=そのほかの死、wolfco=狼CO)。result の `first` は、その人の初手の結果か(書かなければ、その人の最初の結果を初手とする)。`truth` は、答え合わせ用で、計算には使わない。役職の人数は、roles(ダミーを除く参加者ぶん)。
- 数え方: 名乗った人・結果の対象・死者・狼COの人の役職を、人数の範囲で総当たりして、結果の真偽の条件を満たすものを残す。灰は、残った役職をどう配ってもよい。通り数は、役職の配り方の数で、確からしさではない。
- 限界: 結果の出し方の癖は、偽の占いの初手の白・黒だけを入れた(`FAKE_BLACK_FIRST`。仮)。二手目以降、霊能の結果、本物がだれを占うか、偽が白を出す相手の選び方は、入れていない(どの相手も同じ確率として数える)。見込みの数字は、段階の重み(仮)と癖(仮)の結果で、実戦の比率ではない。猫又・狩人は、盤面に入れていない。護衛の成功は、縄に数えない。名乗りの内容は、記録に手で書く(発言から自動では拾わない)。
