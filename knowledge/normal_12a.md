# 通常配役(12A猫)のメモ

通常配役(人狼3人・占い師・霊能者・狩人・猫又・狂人のいる12人村)の、ログから分かったことの一覧。12A猫の練習部屋を作るときの出発点にする。
元にしたのは log17 の1本だけ(12A猫、村人の勝ち、昼1〜昼3の3日)。ほかの16本は、占いなし・人狼1人の4A・5A と、占い入りの6A(log16)で、通常配役の参考にはほとんどならない。log11 の試合後の雑談に通常配役の進行の質疑があるが、実戦の議論ではない(`playbook.md`)。
事実(ログに出ていること)と、解釈・推測を分けて書く。ログから決められないことは「分からないこと」にまとめた。名前は匿名(L、J など)で、`seq` は log17 のイベント番号。立ち回りは `playbook.md` の log17 の節、発言例は `examples.jsonl`(ex484〜ex541)にある。

## 役職設定とその意味

ログの設定: `役職設定【人狼-3,占い師-1,狩人-1,霊能者-1,狂人-1,猫又-1,村人-4,役欠け:あり】`。合計12人(初日犠牲者のダミーを含む)。ダミーの役職は村人で、村人の4人に数える。

| 役職 | 人数 | 夜の行動(ログに出るもの) | 通知 | log17 での動き |
|---|---|---|---|---|
| 人狼 | 3 | 噛み先を選ぶ。夜に人狼どうしでチャットする | 役職通知に仲間の名前。噛みの通知 | D・F・M。噛みは3夜とも F が実行 |
| 占い師 | 1 | 1人を占う | 占い結果(人狼です／人狼ではありません) | L。初日夜に黒、夜1に白。夜1に噛まれた |
| 霊能者 | 1 | なし | 処刑のたびに、処刑された人が人狼かどうか | J。昼1から名乗り、結果の報告と指定を出した |
| 狩人 | 1 | 1人を護衛する | ログに通知なし | C。名乗らず。夜2に噛まれた |
| 猫又 | 1 | ログに行が出ない | なし | E。名乗らず。能力は出なかった |
| 狂人 | 1 | なし | 仲間の名前は出ない | K。村人と同じ動きで、偽の名乗りは出さなかった |
| 村人 | 4(ダミー1を含む) | なし | なし | G・H・I(+初日犠牲者) |

- 勝利の通知(ログのまま): `鯖: 人狼が全滅しました!【村人チーム】の勝利です!`。人狼側の勝ちは `鯖: 人狼が村人の数より多くなりました!【人狼チーム】の勝利です!`(ほかのログ)。
- 事実: log17 の勝敗は、人狼3人の全滅で決まった。狂人 K は最後まで生きていたが、村人チームの勝ちだった。狂人がどちらの陣営として数えられるかは、ログから決められない(狂人が生きていても、人狼が全滅した時点で村人チームの勝ちになった、ということだけ分かる)。
- 「役欠け:あり」の意味は、ログから決められない。4A・5A は あり、6A の log16 は なし、12A猫の log17 は あり。log17 では、設定の役職がすべて、実際の参加者に配られていた。

## 各役職の行動と、ログに出る通知・行の書式

X・Y・Z は名前。ログのまま書く。

| 場面 | ログの行 | 備考 |
|---|---|---|
| 役職の通知 | `鯖→X: あなたは【占い師】です` | 12人全員(初日犠牲者を含む)に1件ずつ。ゲーム開始の前に並ぶ |
| 人狼の役職の通知 | `鯖→X: あなたは【人狼】です　仲間は【Y,Z】です` | 「です」と「仲間」の間は全角空白。仲間の名前はコンマ区切りで、自分は含まない。狂人には仲間の名前が出ない |
| 役職設定 | `鯖: 役職設定【人狼-3,占い師-1,…,役欠け:あり】` | 役職の通知のあと |
| 夜の行動(占い・護衛) | `X→GM: 実行@X→Y` | 占い師は占い、狩人は護衛。どちらの行動かは、実行した人の役職で決まる。ダミー(初日犠牲者)の行も同じ形で、夜0に出る |
| 噛みの行 | `人狼→GM: 実行@X→Y` | 送り手は「人狼」。@の次の X が、実行した人狼(log17 は3夜とも F) |
| 噛みの通知 | `鯖→人狼: Yさんを噛みます` | 噛みの行の直後。人狼に |
| 占い結果の通知 | `鯖→X: Yさんは人狼です` ／ `Yさんは人狼ではありません` | 占い師本人だけに。占いの行の直後 |
| 霊能結果の通知 | `鯖→X: 処刑されたYさんは人狼です` | 霊能者だけに。処刑の死亡通知の直後。夜の死者は対象にならない |
| 死亡の通知 | `鯖: Yさんが死亡しました` | 夜の死者は朝の通知の前、処刑は投票結果の前に出る |
| 人狼の夜チャット | `X→人狼: …` | 人狼どうしだけ。議論の発言ではない |
| 霊界 | `X→霊界: …` | 死者と観戦者。議論の発言ではない |
| 独り言 | `X→X: …` | 自分だけに見える。夜と投票時間によく使われる |
| 投票 | `X→GM: 投票@X→Y` | 生き残り全員が、自分以外の1人に入れる |
| 投票結果 | `鯖: 【投票結果】` の次の行から、人数分の `X(N票)の投票先→Y`。最後に `投票の結果【Y】さんが処刑されます` | N は X が受けた票数。得票数と票先が全員分出る |

## 1日の進行と時刻

- 順番: 役職の通知 → 役職設定 → ゲームを開始します → 夜0 → 朝(昼1)→ 投票時間 → 投票・処刑 → 夜1 → 朝(昼2)→ … → 勝利の通知。
- 1サイクルのログの並び(昼から夜): `鯖: 投票時間になりました。話すのをやめてください。` → 各人の投票の行(独り言が混ざる) → `鯖: Yさんが死亡しました` → 霊能者への通知 → `鯖: 【投票結果】…` → `鯖: 夜になりました…役職の人は能力を実行してください`。
- 夜のログの並び: 各役職の行(占いは行の直後に結果の通知)・人狼の夜チャット・独り言・霊界が混ざる。噛みの行と通知 → `鯖: Yさんが死亡しました`(夜の死者)→ `鯖: 恐ろしい夜が明け、朝になりました。`。
- 夜0: 初日犠牲者(ダミー)が噛まれる(噛みの通知は「初日犠牲者さんを噛みます」)。占い師・狩人・ダミーの行が出る。
- 朝の最初の列: 昼1では、生き残り11人が1回ずつ書いた(seq 52〜62。挨拶・名乗り・冗談。名乗りは D、J、L)。昼3は、霊能者の報告(seq 361)から始まった。昼2は、霊能者の報告と指定が4件目に出た(seq 224)。
- 議論の長さ(発言の件数): 昼1が117件、昼2が78件、昼3が66件。時刻はログにない。議論時間と、延長の有無は不明(延長の通知がログにない。依頼者にも確かめていない)。
- 投票時間のあとの書き込みは、他人に見えない自分宛て(独り言)になる。昼1〜昼3の投票時間に、発言(speech)は0件。
- 日の呼び名: 「2d」「3d」「4d」は、最初の議論の日が2d、次が3d、最終日が4d(初日の夜を1日目と数えるらしい。推測)。「3d朝一」は、その日の朝の最初の発言。
- 発言の中に、名乗りの時刻を争う「@293」「295」が出た。書き込みの時刻を示す残り秒の表示と読める(推測)。

## CO と結果の書式

| 役割 | ログの書式 | 備考 |
|---|---|---|
| 占い師(本物。初日が黒) | `【占いRCO】Mさん→黒` | 昼1の最初の列(seq 61)。結果は「→黒」と言葉で書く |
| 占い(偽。人狼 D。白) | `【占いco:H〇】` | 先出し(seq 53)。〇は白 |
| 占い(偽。出し直し。黒) | `【占いco:F●】` に続けて理由 | 昼2(seq 225)。仲間に黒を出す形。●は黒 |
| 霊能者の名乗り | `【霊能CO】` | 昼1の最初の列(seq 59) |
| 霊能結果の報告 | `【●】` | 前の処刑が人狼だった、の報告と読める(推測)。白の場合の書式は、ログに出ていない |
| 吊り先の指定 | `指定：D`、`指定F`。報告と1件にして `【●】`＋改行＋`指定：D` | 霊能者が出した。昼1は指定がなく、黒先の名乗りで吊り先が決まった |

- 名乗りは挨拶の列の中で、1行の決まった書式で出す。余計な説明は付けない(`discussion_style.md` の型 `co`)。
- 占いの結果は、名前のあとに〇●を付ける形(`H〇`、`F●`)と、「→黒」の形がある。
- 狩人・猫又は、最後まで名乗らなかった。

## 夜の人狼チャットの使われ方

- 件数: 21件・318字。夜0が17件(D 5件、F 6件、M 6件。280字)、夜1が3件(D 1件、F 2件。31字)、夜2が1件(F。7字)。仲間が減るにつれて、短くなった。発言として数えない。
- 使い方(事実): 夜0に、偽の占いをだれが騙るか(D)、白先(H)、猫又の騙り(F が引き受けた)、占いの「RCO」と初手黒の扱い(M の案)を相談した。ダイス(TRPG の1D10、「幸運」)の冗談も入った。夜1は、偽の占い D が仲間の F に黒を出す(切り)ことと、本物の占い師を噛むことの相談。夜2は F が1人で噛み先を書いた。
- 実行された案(事実): D の偽の占い(昼1)、D の F● (昼2)、本物の占い師を噛む(夜1)、狩人を噛む(夜2)。実行されなかった案: F の猫又の騙り、M の初手黒の占い。
- 夜チャットは、噛みの行より前に並ぶ(夜0は、17件のあとに噛みの行)。
- 読み合いの材料になる(事実): 村人の I は、「人狼が3人いたら、夜会話でこのルールの話をしそうだから、H は非狼に見える」と、夜チャットの存在を材料にして H を白く読んだ(ex536)。
- 作戦の細かい中身は `playbook.md` の「人狼の夜チャットの作戦」。

## ルールについて分かったこと(事実)

1. 初日犠牲者(ダミー)は村人で、夜0に噛まれる(seq 48〜50)。
2. 夜0に、占い師・狩人・ダミーの行が出る。占い師の結果は夜0に通知される(seq 16、17、31、32)。
3. 占い結果と霊能結果は、本人だけに通知される。占い師が夜に噛まれて死んだとき、その夜の結果(夜1の K)は、他の人に伝わらない。
4. 人狼は夜に、仲間とチャットできる。噛みを実行する人狼は1人(行の送り手は「人狼」)。噛みの通知は人狼全員に出る。
5. 投票は、生き残り全員が自分以外の1人に入れる。結果で、全員の票先と得票数が出る(seq 189、331、463)。
6. 同票は起きなかった(最多の得票は、昼1が9票、昼2が8票、昼3が6票。2位は2票、1票、1票)。
7. 死者は霊界で話せる(L、M、D、C が死後に書いた)。観戦者(O1〜O4)も霊界に書く。
8. 狩人は、同じ人を2夜続けて護衛できる(C は夜1・夜2とも J)。
9. 霊能者の通知は、処刑された人についてだけ(夜の死者は対象外)。
10. 勝敗は、人狼の全滅の通知で決まった。そのとき、狂人は生きていた。
11. 発言から読める部屋の決まり: 占い師・霊能者が序盤は名乗らず隠れる「占霊潜伏」は、設定上はあり(I「ルール上ありらしい」、K「序盤まで潜伏ありというルール」)。人狼チャットと独り言に「占RCO必須」「RCOになった」「RCO必須じゃない…?」が出た。依頼者の説明: RCO はロケットCO(一発言目の CO)。12A猫では、占いと霊能は RCO。狐のない配役ではロケットCOが強いので、決まりというより約束事として、潜伏は「ない」。

## 初日の占いについて

- 事実:
  - 占い師 L の夜0の行は M(人狼)を占い、通知は「人狼です」(黒)だった(seq 31、32)。
  - 夜0に、占い師の行と、ダミー(初日犠牲者)の行が、同じ「実行@…」の形で出る(seq 16、31)。
  - 夜1に L が占った K の通知は「人狼ではありません」(seq 212、213)。
  - 人狼チャットに「初手黒」「占RCO」が話題として出た(seq 26、34、38)。L の独り言に「RCOになった」(seq 33)。
  - 観戦者 O4 が「12aでランダム白だと狼側が有利ですかね」と書いた(seq 198)。
- 言えること:
  - 依頼者によると、いまの12A猫はランオフ(ランダムなし)で、初日の占い先は占い師が選ぶ形。log17 の L が初日に黒(M)を引けたことと合う。log17 の時点の設定も同じかは分からない(占い師の行も、ダミーの自動の行も、同じ書式で出る)。
  - 初日の占いの結果は、白に決まっているとは限らない(この部屋の12A猫では、黒が出た)。
  - 黒が出た占い師は、昼1の最初の列で名乗れば、黒先は名乗りの直後に即決で吊られうる(log17)。
  - 人狼は、夜0の人狼チャットで、初手黒(初日の黒)を話題にしている。黒が出ることを、想定していたように読める(推測)。
  - 「ランダム白」という言い方が観戦者から出ている。この部屋は「ランダム白」ではなく、結果が黒にもなる設定と読める(推測)。
- 言えないこと:
  - 黒が出る確率。1本だけで、占う対象の範囲も分からない(人狼は3人)。
  - ランダムなら、対象に自分・ダミーが含まれるか。ダミーを占えるか。
  - 白が出た場合の昼1の進行(log16 の6Aは白だったが、規則が同じかは分からない)。
  - 「占RCO必須」の中身(RCO はロケットCOと分かった。log17 の部屋の設定として必須だったか)。log17 の時点の設定が、いまと同じか。

## 分からないこと

- 議論の時間と延長(log17 は延長の通知がない)。
- 同票のときの扱い(log17 は同票がなかった)。
- 猫又の道連れ: 吊られたら生存者からランダムに1人、噛まれたら人狼のうちランダムに1人(人狼online仕様。よみ鯖仕様は、噛んだ人狼)。実際に入れるときは、この online 仕様に従う(依頼者に確認済み)。猫又が自分で相手を選べるか、護衛で噛みを防げるか(防げたら道連れも起きないか)は、確認したい。log17 の猫又は能力を使わず、ログに行も通知も出ない(能力の使い方の書式は、ログから分からない)。
- 人狼チャットの「真猫に黒刺された場合、人外を道連れにできなければ rpp がスタートする」は、依頼者の説明では、次の流れ。偽の占いが真猫に黒を出す→真猫が猫COする→対抗の猫が出る→黒を出された真猫が吊られる→道連れが村に当たる(村道連れ)→2回目の昼(依頼者の数え方で3日目昼)に、狼3・狂1・村4の8人盤面になる→人外側が RPP を宣言して、4:4で RPP する。RPP は、同数なら抽選のパワープレイ(依頼者に確認済み)。
- 進行の目安(依頼者): 3-1 白白白(黒が出ない)は、占いロラ進行で確定。3-1 で黒が出たら、先黒吊りになる可能性が高い。2-1 白進行は、たぶんいちばん多い進行(次の項)。1-1 は、霊指定から決め打ちになりやすい。昼2で黒が出た場合は、本格的に占い対黒のどちらかになる。白が出た場合の決め打ちは、占いか、占いがまだ占っていない所のどれかを、霊が指定する感じ(1-1 の細部は確認したい)。
- 2-1白進行(依頼者): たぶんいちばん多い進行。占い2者がグレーを仮指定し、霊能者が本指定を行う。本指定のタイミングで、指定された猫はギドラCOをする。
- 猫の名乗りと吊り(依頼者): いまの環境では、猫COして対抗の猫が出たら、猫吊りが基本。占いへの対抗黒と同じ型で、可能性をすべて考えるより、環境上確率が高い盤面を想定した吊り・狩人の護衛になっている。猫が2人名乗ったとき、吊るのは、黒を出された方、なければ、どちらかといえば先に出た方。道連れが起きたら本物を吊ったことになり、ほぼ負け。起きなければ偽が確定して、残る猫は放置する。猫COのあとに対抗猫は、まあまあ出る(仮に7割。人狼 : 狂人 = 7 : 3)。先に出たのが偽の割合は、6割くらいでよい(依頼者)。優先は、黒先、次に猫吊り、そのあとに進行。猫が出るのは、昼1だと、黒を出された場合(黒を刺された場合は100%、必ず出る)と、吊りを指定された場合。進行提示が黒吊りの場合は、黒を刺された猫は絶対に出る(伏せたまま吊られることは絶対にない)。ただし、人狼側は猫を確定させたくないので、対抗が出て、真猫が貫通される(CO しても吊られる)のが基本。3-1 で占いロラ進行になった場合だけ、猫が伏せる可能性がある(猫は噛まれないので、依頼者は出てもよいと思う)。今の環境では、先黒吊りになる可能性が高く、そのときは絶対に CO しないといけない。指定された猫は、指示役から「単体で出してほしい」と言われたら、単体で出る。猫のRCO(昼1に即CO)は、今の環境だと基本しない。2-2 盤面は、グレー噛みが起きやすく、RCOのメリットが少ない。3日目(2回目の昼)に猫COするのはあり。2-2 盤面を見ずに朝一で即露出するのは、あまり好ましくない。狩人の護衛は、初手で黒が出された場合は、黒を出した占い(依頼者に確認済み)、黒がなければ真目の占いか霊能。護衛は猫又の噛みを防げる。
- ダミー(初日犠牲者)を占えるか、護衛できるか。
- 護衛が成功した夜の表示(log17 に、護衛が成功した夜がない)。狩人が自分を護衛できるか。
- 狂人が勝敗にどう数えられるか。
- 「役欠け:あり」の意味。
- 「貫通」「回避」「欠損」の正確な意味(`discussion_style.md` の語彙は、使われ方からの推測)。ギドラ(CO)は、依頼者に聞いた(語彙のとおり)。

## ログの読み方の注意

- 引用つきの複数行の投稿(行頭が「名前: 」で始まる引用の行が2行以上続くもの)は、行ごとに別の発言に読まれる。log17 では seq 221・222 がそれ(E の3行の投稿が、G の発言と E の発言に分かれた)。形式から見分けられない。
- 夜と投票時間の独り言に、朝に貼る長い下書きが入ることがある(K、E)。朝の最初の長い投稿は、夜の死亡を反映していないことがある(H は夜に噛まれた C を評価に入れた)。
