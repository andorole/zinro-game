# 立ち回りメモ(観察)

ログ4本から読み取った立ち回り。傾向であって、強さの根拠ではない。次のログで再現しなければ削る。
`seq` は取り込み後のイベント番号で、`examples.jsonl` と同じ(ログごとに振り直し)。A・B は4本とも同じ2人で、C 以降はログごとに別の人。A は log04 だけ人狼で、ほかはすべて村人。
ベースにするのは B、次点は A。C 以降は相手側の動きの参考。

## 共通して見えたこと

- 占いなしの小人数戦(4A・5A)では、役職の情報がない。議論の材料は発言の筋(立場の一貫性、矛盾、動機)だけで、村目／狼目や人外要素をめぐる応酬になる。
- 話題はゲームの中身より、議論そのもの(起点になるか、割り切りか、宣言した人の努力義務)になりやすい。1つの論点を、角度を変えて何度も取り上げる。
- 序盤に情報がないときは、雑談や冗談で場を作る(log02 の色の話、log03 のアイスと駄洒落)。そのあと、誰かが冗談を切って真面目な論点に切り替える。
- 投票は議論のあとに、全員がコマンドで行う。投票前に票先を宣言した人はいない。議論時間が終わったあとの書き込みは、他の人には見えない自分宛ての扱いになる。
- B・A 以外が人狼のとき(3本)は、件数は村人並みに話すが1件が短く、文字量は1割前後(11%、8%、8%)だった。log03 では、発言が少ないこと自体が人外要素として挙げられ、そのまま処刑された。log02 では少なくても見抜かれなかった(村人の票が割れたため)。A が人狼の log04 では、文字量が44%と村人並みでも処刑された。村人の C は11%でも疑われなかった。
- 3人戦(4A)では、第三者の傾きが勝敗を決める。B も A も、第三者に向けて話し、判断を仰ぐ(ex87, ex96, ex127, ex143)。log04 では、第三者の C が B 側についた。
- 村人の A と B は議論の中で対立しても、3本中2本(1448556、log03)で、最終的に同じ相手(人狼)に投票した。

## B と A の動き(3本共通)

- B: 判定役。冗談で場を温め、頃合いで詰める。相手の発言を取り上げて、筋が通っているか、狼目かを言い切る(ex07, ex28, ex48)。相手の名乗りと行動の食い違いを突き(ex29, ex48)、根拠の要素を聞き(ex93)、立場の表明を求める(ex67)。自分が狼ならどうするかを理由に使う(ex49)。発言が少ない人も人外要素に挙げる(ex101)。
- A: 議題を出して動かす役(ex04, ex37, ex86)。雑談では敬語、議論ではタメ口。疑われたら、評価の恣意性を指摘し(ex12)、疑う側の動機を疑い(ex62)、疑いを別の人へ向ける(ex23, ex66, ex83)。立証責任を相手に返し(ex94)、立場は聞かれたら素直に答える(ex69, ex70)。
- 2人は議論の中で対立するが、4本とも会話は途切れず、互いの発言を引いて返している。
- A が人狼のとき(log04)も、型・量・口調は村人のときと変わらない(下の log04)。

## 1448556(4A・占いなし・村人の勝ち)

- 配役: 占いなしの4A(人狼1・村人3。村人の1人は役欠け用の「初日犠牲者」)。実質は A・B(村人)と C(人狼)の3人で、特殊な役職はない。
- 夜: 人狼(C)が初日犠牲者を襲撃した(seq 7〜11)。
- 昼: 議論は1日だけ。議論時間300秒に、延長(90秒)が3回。A が冒頭にした冗談(seq 21)が「起点と言えるか」をめぐって、全員が論じた。
- 投票: 議論終了後に、全員がコマンドで投票した。A→C、B→C、C→A。C が2票で処刑され、村人の勝ち。
- 投票時間の通知(seq 61)のあとは、誰も発言していない。

### 村人側(A・B)

- 役職の情報がないので、人外度は「発言の筋の通り方」で測っていた。前提の誤り、過去の発言との矛盾、論点のずれが根拠になる。
- 疑われたときの A の返し方は段階を踏んでいた。冗談で和らげる(seq 27) → 評価が恣意的だと指摘する(seq 31) → 相手を比較に出して疑いを返す(seq 46) → 相手の読み違いを指摘する(seq 59)。
- 村人どうしでも評価は割れた。B は A に「発言レベルが低そう」という材料を取りつつ(seq 24)、C にはより多くの人外要素を認めた(seq 52)。票は割れず、2人とも C に入れた。疑いの材料が多い人に入れる形。
- B は、相手の過去の発言を引いて矛盾を突くことが多かった(seq 55)。

### 人狼側(C)

- 村人と同じ用語(起点、人外要素、非狼要素)を使って議論に加わっていた。
- 発言は短く、質問が多い(seq 23, 30, 47)。評価には留保が付く(seq 41, 58 の「〜かも」「私の中では」)。
- B からは「なあなあ」な考察と評価され(seq 52)、A からは読み違いを指摘された(seq 59)。このログでは、立場の曖昧さと読み違いが人外要素として数えられた。
- 一方で、A の「どうですか」を引用し、A の「起点のつもりはなかった」という主張を揺さぶる動きもあった(seq 51)。議論に参加しないわけではなく、内容の弱さで見抜かれた。
- 投票は A。B が A の発言レベルに触れていたので、そこに乗ろうとした可能性がある(解釈)。B は乗らなかった。

## log02(5A・占いなし・人狼の勝ち)

- 配役: 占いなしの5A(人狼1・村人4。村人の1人は初日犠牲者)。実質は A・B・C(村人)と D(人狼)の4人。
- 夜: D が初日犠牲者を襲撃した(seq 8〜12)。
- 昼: 議論は1日だけ。議論時間300秒に、延長(90秒)が3回。色の雑談(seq 20〜29)のあと、A が「5A の議論で狼目・村目は出るか」を全員に問い(seq 28)、B が「割り切りなら議論せずスキップするはず」と詰めた(seq 47, 63)。A は B の動機を疑い(seq 73)、C は B をかばって割って入った(seq 76〜83)。
- 投票: A→C、C→A、D→A、B→D。A が2票で処刑された。夜に D が B を襲撃し、村人1・人狼1になって人狼の勝ち。
- 村人が負けた理由は票の割れ。B だけが D に入れ、A と C が互いに入れ合った。
- B は発言では最後まで A を「おかしい」としていた(seq 88)が、投票は D だった。発言と投票が一致しない例。

### 村人側(A・B・C)

- A: 問いを立てて議論を動かす(ex37, ex40, ex44)。疑われると、言う側の動機を疑い(ex62)、疑いを C に向けた(ex66)。立場は聞かれたら素直に答えた(ex69, ex70)。
- B: 断言し、理由を並べ、相手の矛盾や動機を突く(ex43, ex48, ex56)。立場の表明を相手に求める(ex67)。
- C: 他の配役との比較(ex42)と、確認の質問(ex65)が中心。白熱した場面で B をかばい(ex68)、謝った(ex63)。文を2つに分けて送ることがあった(seq 80 → 81)。

### 人狼側(D)

- 発言は短く(平均17字)、同調(ex38, ex41)、質問(ex50, ex54, ex57)、「言語化できない」(ex47)など、当たり障りのない内容が中心。誰も攻撃しなかった。
- 言い切らずに送った発言が3件(seq 52, 79, 87)。
- 疑われないまま、投票では C と同じ A に入れ、村人の票の割れに乗った。
- 1本目の人狼(C)は議論に深く入って見抜かれ、2本目の人狼(D)は浅く入って見抜かれなかった。ただし2本目は村人の票の割れが大きく、人狼の立ち回りだけの結果とは言えない。

## log03(4A・占いなし・村人の勝ち)

- 配役: 占いなしの4A(人狼1・村人3。村人の1人は初日犠牲者)。実質は A・B(村人)と C(人狼)の3人。
- 夜: C が初日犠牲者を襲撃した(seq 8〜11)。
- 昼: 議論は1日だけ。議論時間300秒に、延長(90秒)が3回。挨拶のあと、B が「議論がんばろう。狼探すぞ」と宣言し(seq 20)、情報がないので A のアイスの雑談と B の駄洒落で場が温まった(seq 23〜38)。A が冗談を切って「宣言する人は議論を回す必要がある」と真面目な論点に変え(seq 39)、「努力している／していない」の根拠の挙げ方をめぐって、B と A が応酬した(seq 43〜66)。
- 投票: A→C、B→C、C→B。C が2票で処刑され、村人の勝ち。
- B は C の発言が少ないことを「ショート」として人外要素に挙げ(seq 58)、A も「この状態で C 吊りにならないなら何の議論なのか」と同意した(seq 62)。B は最後に「おやすみ」と冗談めかして締めた(seq 67)。

### 村人側(A・B)

- B: 冗談で場を温め(ex78, ex81)、議論が始まると根拠の要素を求め(ex93)、第三者に判断を仰ぎ(ex96)、発言量の少ない C を挙げた(ex101)。投稿は22件と多く、1件は短め(中央値42字)。
- A: 雑談(ex76, ex77)から入り、冗談を笑いに変えて疑いを返し(ex83)、真面目な論点に切り替えた(ex86)。立証責任を相手に返し(ex94)、最後は B に同意して C に票を入れた(ex105)。
- 2人の応酬の中心は「宣言した人に努力義務があるか」。B は「宣言は様子見としてあり得る」と返し(ex89)、A は「努力義務は濃くなる」と返した(ex91)。決着はつかないまま、C の発言の少なさが先に処理された。

### 人狼側(C)

- 発言は短く(平均18字、文字量の8%)、「そうだな」「まあBのそれはそう」と同意や無難な返事が中心(ex75, ex88, ex92, ex107)。誰の主張にも深入りしなかった。
- B に「喋ってなさすぎる」と挙げられ、A もそれに同意して処刑された。投票は B で、最も発言していた人に入れた。
- 同調だけで立場を持たない発言は、人外要素として数えられた。

## log04(4A・占いなし・村人の勝ち。A が人狼)

- 配役: 占いなしの4A(人狼1・村人3。村人の1人は初日犠牲者)。実質は A(人狼)・B・C(村人)の3人。
- 夜: A が初日犠牲者を襲撃した(seq 8〜11)。
- 昼: 議論は1日だけ。議論時間300秒に、延長(90秒)が3回。挨拶のあと、B と C が「頑張ろう」と言い、A が「パッションを使わず適当に発言していく」という進め方を提案した(seq 21)。B が「適当な発言とパッションを使わないのは相関しない」と返し(seq 25)、序盤をパッションとロジックのどちらで進めるかをめぐって、A と B が最後まで応酬した(seq 25〜66)。
- A は B に「誘導を行おうとしているのかな？」と疑いを向け(seq 38)、のちに B の役職的な動機まで持ち出した(seq 59)。B は「捏造」「曲解」と切り返し、C に文章を読み直すよう求めた(seq 55, 66)。
- 決め手は C。C は終始、短く(平均19字)B寄りに返し(seq 51「誘導って表現は無理がある」、seq 57、seq 62)、A の「C はどっちに寄ってる？」(seq 44)にも、B の名前だけで答えた(seq 45)。
- 投票: A→B、B→A、C→A。A が2票で処刑され、村人の勝ち。

### 人狼側(A)

- 型・量・口調は村人のときと変わらない。文字量は全体の44%(平均71字)で、人狼としては初めて村人並みに話した。
- 進め方の提案から入り(ex110)、冗談(ex111, ex112)を挟み、疑われると「誘導」(ex123)や「役職的な動機」(ex137)を持ち出して反撃した。第三者の指摘は認めて味方につけにいった(ex122)。
- 反論の語尾が「〜でしょう」「〜んじゃないですかね」と丁寧寄りになる場面がある(ex131, ex137)。
- 負けた理由は、第三者(C)に受け入れられなかったこと。「誘導」という見立ては、B にも C にも「曲がりすぎ」「無理がある」と受け取られた。B は A 自身の発言を引用して、A の一貫性のなさを示した(ex124, ex130)。
- 最後は、説明は尽くしたと述べ、B を黒扱いして締めた(ex141)。

### 村人側(B・C)

- B: 「捏造」「言ってないことを言ったことにしてる」と切り返し(ex133, ex136)、第三者の C に文章を読み直すよう求めた(ex134, ex143)。A が否定したパッションで、A に言い返した(ex124)。
- C: 短い発言(中央値20字)で、B の発言の読みを確かめ(ex126)、B をかばい(ex135)、A の「ロジック強め」に「違うと思う」と返した(ex142)。

## 投票と全体宣言

- 全体宣言(票先を先に全員へ宣言する運用)が、1本目の議論の題材になった。B の整理は次のとおり。
  - メリット: 怪しんでいる位置が明白になり、考察が捗る(seq 28, 35)。
  - デメリット: 票先が人狼に分かる(seq 28)。
- 4本とも宣言はせず、各自が投票コマンドで投票した。宣言するかどうかは、場の合意に従う。

## まだ分からないこと

- B が人狼のときの動き。A が人狼のログは1本(log04)だけ。
- 占いあり・役職あり・多人数・複数日の動き(CO、結果報告、護衛など)。
- 発言のタイミング。ログに時刻がない。
- 「浅く入る」人狼の立ち回りが再現するか。
- 「起点」「割り切り」「宣言の努力義務」を重んじる議論の流れが、この場の標準なのか、この数人の癖なのか。
